## Phase 2 — Priority 0 readiness
Required before any external launch:
- production route and account flow work from a clean browser
- privacy, terms, contact, support, and feedback are live
- first-party events cover visit -> follow start -> follow created -> useful observation/change -> return/share
- UTM source/medium/campaign are retained without invasive tracking
- screenshots and share cards exist
- canonical launch copy exists
- owner can inspect failures and feedback
- weekly learning review is ready
