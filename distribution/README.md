# Clarity Belongs distribution system

## What Clarity Belongs is
Clarity Belongs is one monitoring service: **tell Clarity what matters and it keeps an eye on public information for you**. It observes public sources over time, stores evidence, detects changes or availability transitions, and gives the user history to review.

The public launch model is not a catalog of dozens of unrelated apps. The 15 public watch types are capabilities underneath one service. Learn is the educational/search layer. Free Local Tools are a separate downloadable utility collection. The desktop portfolio is future work.

## What it is not
- not an AI truth engine or decision-maker
- not a universal web crawler
- not a private-account monitoring service
- not a proprietary price, reputation, blacklist, or travel database
- not a directory of every internal monitor identity
- not a substitute for authoritative sources when a deadline, safety notice, filing, or policy matters

## Product families
1. **Clarity monitoring service** — 15 public watch capabilities sharing one follow/history/alert system.
2. **Learn** — 22 search-oriented guides mapped to public watch capabilities.
3. **Free Local Tools** — 10 no-account PowerShell utilities for local information organization.
4. **Clarity Desktop** — 10 documented candidate products; roadmap only, not promotion-ready.

## Common value proposition
Clarity reduces repeated manual checking. The core proof is not "AI knows the answer"; it is **visible source evidence, history, change detection, recovery state, and user control**.

## Source of truth
- `distribution/data/inventory.csv` — canonical item inventory and readiness
- `distribution/data/actions.csv` — one real human action per row
- `distribution/products/` — full market/distribution maps for the 15 public watches
- `distribution/campaigns/` — shared channel plans
- `distribution/PRIORITIES.md` — execution order
- `distribution/ROADMAP.md` — mapping/readiness work
- `distribution/RECONCILIATION.md` — portfolio accounting and gaps

No external promotion is authorized by these files. Mapping first; execution is a separate decision.
