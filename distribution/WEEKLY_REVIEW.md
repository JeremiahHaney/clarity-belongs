# Weekly distribution learning review

Use this once per week after external distribution begins. Keep the review evidence-based and tie product changes to observed behavior.

## Funnel
Record by product and campaign:
- visits
- follow starts
- follows created
- meaningful observations/change/failure events
- return users
- shares
- feedback items

## Questions
1. Which product attracted actual users?
2. Which source produced completed use rather than clicks?
3. What search phrase or content angle worked?
4. Where did users abandon the workflow?
5. Which products caused repeat use?
6. Which outputs were shared?
7. What feedback repeated?
8. What product family seems to have real pull?
9. Which channels produced noise but no useful use?
10. What should development improve next based on evidence?

## Decision record
For each material decision, record:
- evidence observed
- interpretation
- product/distribution change
- owner
- next measurement
- date to revisit

The purpose is to prevent Clarity from becoming an endless-build project. Distribution evidence must be allowed to change development priorities.
