# Shared campaign: search and Learn

Learn is the strongest reusable acquisition system already implemented.

## Existing assets
22 indexable guides map to the 15 approved public watches. The strategy is to answer specific monitoring questions and lead directly into the matching watch workflow.

## Priority search clusters
1. website change monitoring
2. website uptime / HTTP status
3. SSL and domain expiration
4. DNS / nameserver history
5. MX / SPF / DKIM / DMARC change monitoring
6. redirect and broken-link monitoring
7. public API/service outage monitoring

## Rules
- Do not create thin pages merely to increase page count.
- Every new guide must answer a distinct user question and map to a real public product.
- Demonstrate the exact product behavior and limitations.
- Link Learn -> watch page -> Watch Something, and product pages -> relevant Learn guides.
- Measure search landing -> follow start -> follow created -> return.
