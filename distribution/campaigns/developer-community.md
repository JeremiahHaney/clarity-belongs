# Shared campaign: developer and operations communities

## Primary current target
**r/devops weekly self-promotion thread**
- Current 2026 weekly threads explicitly invite projects, ideas, and repos.
- Use only the designated thread unless current subreddit rules explicitly permit a standalone post.
- Best fit: uptime, HTTP status, API endpoint uptime, service outage, DNS, TLS, redirect, and broken-link watches.
- Lead with the operational problem and request feedback; disclose that the product is ours.

Evidence example: https://www.reddit.com/r/devops/comments/1wfvo9y/weekly_self_promotion_thread/

## Conditional targets
- r/webdev — community discussion indicates occasional relevant self-promotion may be tolerated, but excessive promotion is removed. Treat as **Needs recheck**, not Ready.
- r/selfhosted — Skip for hosted Clarity unless a genuinely self-hostable release exists. Current rules require promoted apps to be self-hostable, released, and documented.
- Hacker News / Show HN — use only when a stranger can try the product and we can stay present for technical questions. Re-read current Show HN guidance before posting.
